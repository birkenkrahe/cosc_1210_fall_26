# Computer Science I (with Python)


# What's in this repo?

-   Course materials for COSC 1210 - Computer Science I (with Python)
-   `org/agenda.org`: the agenda for every session
-   `pdf/`: syllabus, slides and handouts
-   `org/`: lecture notes and code-alongs
-   `ipynb/`: notebooks for practice and assignments - open them in
    Google Colab
-   `assignments/`: assignment briefs; `data/`: data sets
-   Emacs Org-mode files (`.org`) are rendered as Markdown on GitHub
    (not in the mobile app, but in a mobile browser).
-   Reference links in the files lead to a 404 error. You always find
    the references at the end of a file.
-   For a table of contents, open the bullet point list menu at the top
    of a file.

# How to use this repo

-   You don't need a GitHub account to read or download the files.
-   On a desktop or laptop, open the `.org` files directly on GitHub.
-   To open a notebook in Colab, follow the Colab link given in class or
    on Canvas.
-   Check regularly for changes, or watch the repo (needs a GitHub
    account) to get notified.
