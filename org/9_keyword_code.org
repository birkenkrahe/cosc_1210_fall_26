    Character Meaning
    --------- ----------------------------------------------------------
    'r'       open for reading (default)

    't'       text mode (default)
    '+'       open a disk file for updating (reading and writing)

    raises an `FileExistsError` if the file already exists.

    Python distinguishes between files opened in binary and text modes,
    even when the underlying operating system doesn't.  Files opened in
    binary mode (appending 'b' to the mode argument) return contents as
    bytes objects without any decoding.  In text mode (the default, or when
    't' is appended to the mode argument), the contents of the file are
    returned as strings, the bytes having been first decoded using a
    platform-dependent encoding or using the specified encoding if given.

* Practice: how many keywords?

Pseudocode:
1) initialize counter
2) go through every line in the file
3) strip whitespace around every word
4) increment counter
5) when done with loop, return count

#+begin_src python :results output :exports both :session *Python* 
  def count_keywords(sentence):
      """Return how many keywords from keywords.txt appear in sentence."""
      count = 0
      for line in open("keywords.txt"):
          word = line.strip()
          if word in sentence.lower():
              count += 1
      return count

  print(count_keywords("My mother and my father never talk."))
  print(count_keywords("Sorry, I forgot."))
  print(count_keywords("The weather is nice."))
#+end_src
