* Lab: Crew capsules (live coding)

Goal: showing the *process*, not only the result. Students type along in
their own editor - we make three mistakes on purpose.

* The 10 solution steps

1) Setup: python, editor, notebook
2) Understand the problem
3) Build a program header (in the editor) (~"""~)
4) Solve the problem away from the computer
5) Build a function with a fixed value (~def~)
6) Build a decision tree (~if~ ... ~else~)
7) Test with a second fixed value to expose the bug, then remove the fixed value
8) Replace the fixed value with ~input()~
9) Loop over multiple inputs (~for~ loop)
10) Try edge cases and compare exactly against the samples

** The recipe

1. Solve one example by hand -> algorithm
2. Write the function and call it with a fixed value.
3. Add the decision and test every branch.

* Final program with edge case guardrail

#+begin_src python :noeval :results output :exports both :session *Python* :python python3
  """
  Title:  Crew capsules
  Name:   Birkenkrahe, Marcus
  Input:  one integer: the number of crew members
  Output: <n> crew: <c> capsules, all aboard (if nobody is left over)
          <n> crew: <c> capsules, <w> waiting (otherwise)
  AI use: used to interpret one runtime error message (TypeError on
          unconverted input()); no AI-generated code
  """

  # board the crew
  def board(crew):
      if crew == 0:
          print("There must be > 0 crew members")
          exit()
          # COMPUTE capsules: 4 crew members per capsule
      capsules = crew // 4
      # COMPUTE waiting: remaining crew members
      waiting = crew % 4
      if waiting == 0:
          print(f"{crew} crew: {capsules} capsules, all aboard")
      else:
          print(f"{crew} crew: {capsules} capsules, {waiting} waiting")

  # main
  for _ in range(2):
      board(int(input()))
#+end_src
