* Circle Calculator

This assignment uses only chapter 2 material: variables, ~import~, the
~math~ module and the dot operator, ~**~, ~round~, ~type~, comparisons,
and ~print~. No ~if~, no loops, no function definitions - those come
later.

Everything is driven by one variable:

#+begin_example

#+end_example

** Part 1 - Area and circumference

- ~import~ the ~math~ module so you can use ~math.pi~.
- Compute the *area* (~math.pi * r**2~) and store it in a variable.
- Compute the *circumference* (~2 * math.pi * r~) and store it in a
  variable.
- Print both, each rounded to 2 decimal places.
- On the next line, print ~type(area)~.

** Part 2 - Labelled output

Print three lines that name each value, for example:

#+begin_example

#+end_example

The numbers must come from your variables, not from re-typing them
inside the quotes.

** Part 3 - Compare them

The area counts square centimetres; the circumference counts
centimetres. For ~r = 5~, which number is bigger?

- Print the result of ~area > circumference~ (this is a ~bool~).
- Then change ~r~ to ~1~ and run the whole program again. What does the
  comparison print now?

** Given - draw the circle

Paste this cell *after* your Part 1 code and run it. You are not
expected to understand it yet - it just draws a circle of radius ~r~
with your numbers in the title.

#+begin_example
  # --- given: run this cell, you'll learn how it works in a later chapter ---
  import matplotlib.pyplot as plt

  fig, ax = plt.subplots()
  ax.add_patch(plt.Circle((0, 0), r, fill=False, linewidth=2))
  ax.set_xlim(-r - 1, r + 1)
  ax.set_ylim(-r - 1, r + 1)
  ax.set_aspect("equal")                 # so it's a circle, not an ellipse
  ax.set_title("r = " + str(r) +
               "   area = " + str(area) +
               "   circumference = " + str(circumference))
  plt.show()
#+end_example

If the title shows a long decimal, round ~area~ and ~circumference~ in
your Part 1 code and it tidies up here too.
