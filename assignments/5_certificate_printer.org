  # function definition
  def banner(text, width=24):
      """Prints a rule, a centered text and another rule of width

      width -- width of rule and text field - default=24 (number)
      text  -- input text for the banner (string)
      returns: nothing
      """
      rule(width)
      print(text.center(width))
      rule(width)

  # function calls: with and without the optional argument
  banner("CERTIFICATE", 40)

  def certificate(name, course, grade):
      """Prints named course certificate with grade

      name   -- student name (string)

#+begin_src python :results output :exports both :session *Python* :python python3
  # function definition
  def print_copies(name, course, grade, copies):
      """Print named course certificates with grade

      name -- Name of the student (string)
      course -- Course the student completed (string)
      grade -- Grade the student received (string)
      copies -- Number of certificates printed (whole number)
      Returns: nothing
      """
      for _ in range(copies):
          certificate(name, course, grade)
          print()

** Write-up

1) =rule= has to work the same way regardless of who calls it or how
   many arguments they give it. Since it has a default
   (~length=24~), every caller can either pass a length or not, and
   =rule= does not need to know or care which function is calling it.

2) A fixed =40= inside =banner= would mean the *only* way to get a
   =20=-character banner is to edit the source code of =banner= and
   change every existing call that relied on =40=. With the =width=
   parameter, a caller just passes a different number -
   =banner("...", 20)= - and =banner= itself never changes.

3) =certificate("Elizabeth Bennet", "COSC 1210", "A")= calls =banner=,
   which calls =rule= twice (once before, once after printing the
   centered text); control returns to =banner=, which returns to
   =certificate=; =certificate= then prints two lines directly and
   calls =rule= once more before returning to whatever called it (the
   main program): main -> certificate -> banner -> rule -> banner ->
   rule -> banner -> certificate -> rule -> certificate -> main.

4) =name=, =course=, and =grade= are *parameters* - names that belong
   to the function's definition. ="Elizabeth Bennet"=, ="COSC 1210"=,
   and ="A"= are the *arguments* - the actual values supplied in this
   particular call. Calling =certificate= again with different
   arguments reuses the same three parameters.

5) With =copies= = 2, =range(2)= produces 0 and 1, in that order, so the
   loop body runs twice - once per certificate. The loop counter is
   never used inside the body, it's a dummy variable; only the *number*
   of repetitions matters.
