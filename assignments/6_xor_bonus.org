* The XOR Formula

*Bonus exercise - worth 5 points.* It is available until midterm.

Python has ~and~, ~or~ and ~not~, but no keyword for the *exclusive
or*, "one or the other, but not both". It is written *XOR*: ~A XOR B~
is ~True~ exactly when *one* of =A= and =B= is ~True~ - not both, not
neither. You can build it from the three operators you know. In this
exercise you *prove* that two formulas do the job:

1. ~(A or B) and not (A and B)~ - "at least one, but not both"
2. ~(A and not B) or (not A and B)~ - "A without B, or B without A"

Python does have a short form: ~a ^ b~ is XOR *for booleans*. On
integers, ~^~ works on the bits instead (~1 ^ 2~ is ~3~), so do not use
it for numbers. The point of this exercise is to see /why/ the formulas
above work, and to prove it.

** Task 4: Proof by checking

- *Create* a level-2 headline that says =Task 4: Proof by checking=.
- Two booleans have only 2 x 2 = 4 combinations. If a formula agrees
  with the definition in all four, it is XOR - that is a proof. But you
  should not have to compare the columns with your eyes.
- *Write* a check for the first formula. Complete this skeleton: =ok=
  starts as ~True~ and is set to ~False~ if the formula *differs* from
  ~a != b~ in any combination (~!=~ means "is not equal"). Never set
  it back to ~True~ inside the loops.

  #+begin_src python :eval no
    ok = True
    for a in (True, False):
        for b in (True, False):
            if ...:            # the formula differs from a != b
                ok = False
    print("Formula 1 holds:", ok)
  #+end_src

- *Do* the same for the second formula.
- Expected output:

#+begin_example

Formula 2 holds: True
#+end_example
